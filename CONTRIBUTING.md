# Contributing to ReverseDrop

Thank you for your interest in contributing to ReverseDrop.

## How to Contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests: `go test ./...`
5. Run vet: `go vet ./...`
6. Run race detector: `go test -race ./...`
7. Submit a pull request

## Code of Conduct

Be respectful and constructive.
